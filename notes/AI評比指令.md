# FlowerChan Website — AI 評比指令

> 用途：貼給 OpenAI / Grok / Gemini，請它們為小花店網站做專業評比。
> 直接複製下方分隔線內的全部內容貼上即可。

---

```
你是一位資深的網頁設計與前端工程審查專家。請評比這個花店網站，並以 1–10 分為各面向評分，附上具體可執行的修改建議（不要只給籠統評語）。

【網站網址】
正式站：https://flowerchan.com
（如需測試最新改版：https://redesign--flowerchan.netlify.app）

【背景】
- 台灣台北大安區的實體手作花店「Flower Chan 小花店」官方網站
- 目標客群：送禮、婚禮、企業客戶，以及對花藝課程有興趣的人
- 技術：純靜態網站（HTML + 原生 JS + CSS），資料由 JSON 動態載入，部署於 Netlify
- 品牌調性：清新、溫柔、手作感；主色深綠 #2D4A3E、金 #E8B84B、奶油底、花苞粉
- 四大花品類別：花束、桌花、高架花籃、蘭花；另有花藝課程區
- 主要轉換動作：填寫訂購表單、LINE 詢問

【請依以下面向逐項評分（1–10）並說明理由與改法】
1. 視覺設計與品牌一致性（配色、字體、排版、留白、整體質感）
2. 使用者體驗 UX（導覽邏輯、資訊架構、轉換路徑是否直覺、CTA 是否清楚）
3. 響應式設計 RWD（手機、平板、桌機的呈現與可用性）
4. 效能（載入速度、圖片最佳化、CLS 版面位移、LCP）
5. SEO（title/description、Open Graph、結構化資料 JSON-LD、語意化標籤、在地搜尋）
6. 無障礙 A11y（色彩對比、鍵盤操作、焦點狀態、alt 文字、ARIA）
7. 文案與內容（是否打動人、是否符合品牌語氣、是否有錯字或邏輯問題）
8. 信任感與轉換力（從客人角度：會不會放心下單？少了什麼資訊？）

【輸出格式】
- 先給一個總分與一句話總評
- 各面向：分數 + 2~3 點具體觀察 + 對應的修改建議
- 最後列「優先處理 Top 5」清單，依影響力排序

【已知狀況，請納入考量但不要當缺陷扣分】
- 高架花籃、蘭花、課程的照片目前為暫用佔位圖，正式照片待業主提供
- JSON-LD 結構化資料的營業時間欄位尚待補上
- 部分花品為測試資料

請用繁體中文回答。
```

## 設計重點（給自己看）
- 先框定「審查專家」角色拉高評審水準
- 給足背景避免誤判技術與商業情境
- 要求逐項評分＋具體改法，避免空話
- Top 5 排序方便抓重點
- 「已知狀況」段讓評審聚焦設計與架構，不把暫用內容當缺陷
